# RFC-0008

# Plain v1.0.0 Release Candidate

---

## Status

Final milestone before Plain v1.0.0.

This RFC does NOT introduce new language features.

The language syntax is now frozen.

Only bugs, polish, ecosystem work, documentation, compatibility and release preparation are allowed.

---

# Development Rules

Follow ONLY this RFC.

Do NOT invent new syntax.

Do NOT introduce new keywords.

Do NOT redesign the language.

Do NOT change existing behaviour unless fixing a bug.

Do NOT remove backwards compatibility.

Every previous test must continue passing.

If an improvement is not required for v1.0, leave it for v1.1.

---

# Goal

Prepare Plain for its first stable release.

This milestone is about quality.

Not features.
