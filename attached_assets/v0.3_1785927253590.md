# Feature 1 — Runtime Package System

Implement runtime package resolution.

Support:

use express
use sqlite
use fs
use path

The compiler should translate these into proper JavaScript imports or require() statements depending on the generator architecture.

Unknown packages should produce friendly compiler errors.

# Feature 2 — Express Runtime

Support:

use express

remember app as express()

listen on 3000

    show "Server running"

done

Compile into a working Express server.

# Feature 4 — Request Object
