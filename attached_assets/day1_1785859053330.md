Today we are building the first version of Plain.

Create the project structure:

compiler/
lexer.js
parser.js
generator.js
cli.js

The language only supports:

remember
show

Example:

remember name as "Ayokunle"

show name

The compiler should convert it into JavaScript:

const name = "Ayokunle";

console.log(name);

Implement:

- lexer
- parser
- AST
- JavaScript generator
- CLI

Running:

node cli.js examples/hello.pln

should generate JavaScript and execute it using Node.

Do not add any extra features.
