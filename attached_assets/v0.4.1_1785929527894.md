# v0.4.1 — Multi-file Package System

## Goal

Allow Plain projects to be split across multiple `.pln` files.

This is the ONLY feature in this milestone.

---

## Feature 1 — Plain Imports

Support:

import "./math.pln"

import "./utils.pln"

Imports must resolve relative paths.

Imported files compile before the entry file.

Duplicate imports should only compile once.

---

## Feature 2 — Dependency Graph

Build a dependency graph.

Requirements:

- recursive imports
- nested imports
- detect duplicate imports
- deterministic compile order

---

## Feature 3 — Circular Imports

Detect:

A imports B

B imports A

Produce a friendly compiler error.

Do NOT attempt to compile.

---

## Feature 4 — CLI

Support:

plain run app.pln

where app.pln imports other Plain files.

No syntax changes.

---

## Feature 5 — JavaScript Output

Generate ONE JavaScript output that combines every imported file in dependency order.

No duplicate code.

---

## Feature 6 — Tests

Add tests for:

- simple imports
- nested imports
- duplicate imports
- circular imports
- missing files

All previous tests must continue passing.
