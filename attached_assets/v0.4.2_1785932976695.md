# Goal

Turn Plain into a language that can manage projects without relying on npm for everything.

This RFC focuses on the CLI and project management.

It does NOT introduce new language syntax.

---

# Feature 1 — plain init

Implement:

plain init

Creates:

plain.json

Example:

{
    "name": "my-app",
    "version": "0.1.0",
    "entry": "app.pln"
}

If plain.json already exists:

Display:

Project already initialized.

---

# Feature 2 — plain install

Support:

plain install

Reads:

plain.json

Installs all dependencies listed.

For now this simply runs npm install for JavaScript packages.

No remote Plain package registry yet.

---

# Feature 3 — plain add

Support:

plain add express

plain add better-sqlite3

Behavior:

- installs package
- adds dependency into plain.json
- prevents duplicates

---

# Feature 4 — plain remove

Support:

plain remove express

Behavior:

- removes dependency
- updates plain.json
- uninstalls package

---

# Feature 5 — plain update

Support:

plain update

Updates installed npm packages.

---

# Feature 6 — Dependency Validation

Before compiling:

Check:

- imported Plain files exist
- required npm packages exist

Friendly errors only.

Example:

Package "express" is not installed.

Run:

plain add express
