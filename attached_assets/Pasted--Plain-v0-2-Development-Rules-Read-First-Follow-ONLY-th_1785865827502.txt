# Plain v0.2 Development

## Rules (Read First)

- Follow ONLY this specification.
- Do NOT invent syntax.
- Do NOT rename keywords.
- Do NOT change existing language behaviour.
- Keep every existing test passing.
- All new features require tests.
- If implementation conflicts with the specification, stop and report the conflict instead of making assumptions.
- When complete, stop. Do not continue to future versions.

---

# Goal

Upgrade Plain from a small demonstration language into a language that can write larger real-world programs.

Every previous feature must continue working.

---

# Existing Features

The following already exist and MUST continue working exactly as before:

- remember
- becomes
- show
- if
- otherwise
- done
- make
- give
- function calls
- comparisons
- +

Do not modify their syntax.

---

# Feature 1 — Arrays

Support array literals.

Example:

remember players as [
    "Haaland",
    "Foden",
    "Rodri"
]

Support indexing.

show players[0]

Support assignment.

players[1] becomes "Palmer"

Generate equivalent JavaScript arrays.

Add parser tests.

---

# Feature 2 — Objects

Support object literals.

Example:

remember user as

    name is "Ayokunle"

    age is 17

    country is "Nigeria"

done

Property access:

show user.name

Property assignment:

user.age becomes 18

Generate JavaScript objects.

Add tests.

---

# Feature 3 — Loops

Implement:

for each item in players

    show item

done

Generate JavaScript:

for (const item of players)

Add tests.

---

# Feature 4 — While

Implement:

while age is less than 18

    age becomes age + 1

done

Generate JavaScript while loops.

Add tests.

---

# Feature 5 — Standard Library

Create built-in functions.

length(array)

uppercase(text)

lowercase(text)

random()

round(number)

These should compile into JavaScript equivalents.

Document every built-in.

Add tests.

---

# Feature 6 — Imports

Implement:

use math

use sqlite

Parser support only.

No runtime packages yet.

The compiler should generate placeholder imports.

The syntax must be stable for future versions.

---

# Feature 7 — CLI Improvements

Support:

plain run file.pln

plain build file.pln

plain version

plain help

Support argument parsing.

Improve CLI help output.

---

# Feature 8 — npm Preparation

Prepare the project for npm publishing.

Requirements:

- package.json completed
- bin configured

Example:

"bin": {
    "plain": "./compiler/cli.js"
}

Ensure:

npm install

works correctly.

Ensure:

plain run hello.pln

works after global installation.

Do not publish.

Only prepare the package.

Update:

Examples

Document every new language feature.

# Feature 10 — Testing

Expand test coverage.
