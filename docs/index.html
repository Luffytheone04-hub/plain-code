Plain is an Intent-Oriented Programming Language. Write programs the way you'd explain them to a person. The compiler handles the rest.

const name = "Ayokunle";
const age  = 17;

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Teenager");
}

    console.log(i);

Setup

Quick Start

Plain compiles .pln files to JavaScript and runs them with Node.js. No configuration required.

Install globally via npm npm install -g @ayoxx/plain-code
Create a project
plain new myapp
cd myapp
plain install
plain run app.pln
🔍

plain check

Validate syntax without running. Great for CI pipelines.

✨

plain fmt

Auto-format your .pln file with consistent indentation and spacing.

📦

plain add

Install npm packages and record them in plain.json.

🔨

plain build

Compile to .js without executing — inspect the output.

Database

SQLite Developer Experience

Inline SQL blocks compile to better-sqlite3 calls — no ORM, just SQL written naturally.

database.pln
database "app.db"

execute
    CREATE TABLE IF NOT EXISTS users (
        id   INTEGER PRIMARY KEY,
        name TEXT NOT NULL
    )
done

insert
    INSERT INTO users (name) VALUES ('Alice')
done

query
    SELECT * FROM users
done
PlainCompiles to

query ... donedb.prepare(`...`).all()
insert ... donedb.prepare(`...`).run()
update ... donedb.prepare(`...`).run()
delete ... donedb.prepare(`...`).run()
execute ... donedb.exec(`...`)
