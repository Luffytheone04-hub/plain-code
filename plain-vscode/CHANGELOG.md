# Plain Language Extension — Changelog

## [1.0.0]

- Version bumped to match Plain v1.0.0 stable release
- No grammar or snippet changes — all v0.6 keywords remain fully highlighted

## [0.6.0]

- Updated TextMate grammar with all v0.6 keywords:
  `above`, `below`, `at`, `least`, `most`, `not`, `empty`, `contains`,
  `starts`, `ends`, `with`, `between`, `and`, `every`, `web`, `route`,
  `start`, `database`, `query`, `insert`, `update`, `delete`, `execute`
- Snippets added for common Plain patterns
- Extension version matches compiler version (0.6.0)

## [0.5.0]

- Initial release
- Syntax highlighting for all Plain keywords
- Language configuration: auto-closing pairs, comment toggling, bracket matching, code folding
- File icon for `.pln` files
- Language registration
