# Plain for MT Manager

Syntax highlighting for the Plain programming language in MT Manager.

## Installation

1. Download `Plain.mtsx`.
2. Open MT Manager.
3. Import the syntax package.
4. Open any `.pln` file.

## Features

- Syntax highlighting
- Keywords
- Strings
- Numbers
- Comments
- Functions
- Comparisons
- Web and SQLite keywords
- Runtime standard library

Compatible with Plain v1.0.0.
