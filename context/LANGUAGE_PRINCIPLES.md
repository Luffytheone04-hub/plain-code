# Plain Language Principles

1. Code should read like clear English.
2. One obvious way to do something.
3. Beginner-friendly first.
4. Explicit is better than clever.
5. Consistency beats convenience.
6. Backwards compatibility matters.
7. Every feature must justify its existence.
8. If JavaScript is simpler here, compile to JavaScript.
9. Error messages should teach.
10. Plain is a language, not a JavaScript clone.
